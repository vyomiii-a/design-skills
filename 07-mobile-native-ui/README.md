# Mobile Native UI

- **expo-design-system** — Design-token theme system (colour, spacing, type, radius, motion) inside an Expo app.
- **expo-native-ui** — Native-feeling Expo screens: Apple HIG, semantic colours, SF Symbols, native controls.
- **expo-ui** — @expo/ui: real SwiftUI on iOS and Jetpack Compose on Android.
- **mobile-android-design** — Material Design 3 and Jetpack Compose patterns for Android.
- **compose-animations** — Jetpack Compose motion: enter/exit, property, colour and size transitions.
- **adaptive** — Make an Android app's UI adapt to phones, tablets, foldables and desktop.
- **edge-to-edge** — Migrate a Jetpack Compose app to adaptive edge-to-edge layout.
- **styles** — Jetpack Compose Styles API integration.
- **ios-accessibility** — SwiftUI/UIKit accessibility: VoiceOver, Dynamic Type, focus, contrast.
